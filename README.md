## Featured Projects

### [StartupScout](https://github.com/sanjayk2004/StartupScout)

A MERN stack startup discovery and investor networking platform featuring role-based authentication and funding-related features.

**Technologies:** React · Node.js · Express.js · MongoDB

### Sign Language &amp; Braille Converter

An accessibility-focused project for sign language recognition, text and audio conversion, text-to-Braille conversion, and Braille OCR.

**Focus:** Computer vision · OCR · Text/audio processing · Braille

### [Music Recommendation System](https://github.com/sanjayk2004/music-recommendation-system-using-streamlit)
